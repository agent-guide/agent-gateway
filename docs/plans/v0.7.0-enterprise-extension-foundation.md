## ConfigStore-only configuration

The implemented principle is recorded in
[Enterprise Extension Contract, section 11.3.1](../design/enterprise-extension-contract.md#1131-principle-host-independent-extension-configuration).
Caddyfile owns Caddy host wiring; internal extensions use only ConfigStore in
both server modes. API and Bundle apply retain dependency validation, failure
isolation, secret-reference preservation and generation leases. Static extension
inputs, source metadata and static ownership conflicts have been removed.
Provider, route and other resource configuration ownership is unchanged.

Process contracts configure extensions through API/Bundle apply and restart
both hosts to verify persisted envelopes and prepared Admin resources.
Static-input rejection, dependency and mutation failure isolation,
protocol/stream/cancellation/usage and sink lifecycle checks remain candidate
proof until the published dependency gates pass.
