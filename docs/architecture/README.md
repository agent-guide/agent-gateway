# Architecture

This section describes how the checked-in system currently runs: component
ownership, request and control flow, persistence, lifecycle, failure handling,
and implemented extension points. Proposed behavior belongs in `design/`, not
here. When implementation and an architecture page disagree, the code is the
source of truth and the page must be corrected.
