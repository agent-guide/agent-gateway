# Releases

This section contains durable release notes. A release note explains what
changed between published tags from an operator and integrator perspective; it
does not replace architecture, design, guide, or reference documentation.

Each release note should contain, where applicable:

- added and changed capabilities;
- fixed user-visible behavior;
- compatibility and migration requirements;
- known limitations;
- the verification performed before tagging.

The versioned file in this directory is the source for the corresponding
hosted release description. Development progress and completed implementation
checklists do not belong here.
