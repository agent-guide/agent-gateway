# v0.8.0-preview.2

Changes since v0.8.0-preview.1:

- Support Responses custom tools, including Codex `apply_patch`, via Chat with restored call identities and explicit history. Grammar tools default to rejection; `responses_custom_tool_grammar=prompt` enables instruction-only emulation.
- Add ACP turn diagnostics for investigating execution failures.
- Share Connector egress policy across HTTP API and MCP HTTP/SSE, with optional `public_only` restrictions and exact origin exceptions.
- Fix digest pinning for first-run archives and add immutable preview publication recovery.

**Upgrade:** replace the HTTP-only egress policy-file option with host-owned `connector_egress` settings (standalone: `--connector-egress-mode` / `--connector-egress-allow-origin`). From v0.7.x, follow the [upgrade guide](../guides/upgrade.md#upgrading-to-v080-preview1).

Preview interfaces may change. Existing [known limits](v0.8.0-preview.1.md#known-limits) still apply. This prerelease does not update `latest`.

**Verification:** local source tests/race/vet/build, immutable consumer contracts, adoption checks, process smoke, macOS arm64 archive and digest-pinned first-run packaging passed. The [Release workflow](https://github.com/agent-guide/agent-gateway/actions/workflows/release.yml) additionally gates publication on all native archives, image smoke/scans, first-run replay, checksums and provenance.
