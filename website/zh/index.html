为什么需要网关

启动一个 Agent 很容易，运营它很难。

当 Agent 开始调用模型和执行工具，团队需要知道谁发起了 Turn、访问了哪些 资源、谁批准了动作，以及故障发生在哪里。AgentGuide 把治理路径上的流量 转换成可核验的证据和可执行的控制。

观测

把网关流量变成结构化证据

LLM 请求、MCP 工具调用和 agent 轮次产生持久化用量事件：token （含缓存与推理 token）、时延和错误。Agent 归属明确时写入归因； builtin 轮次始终显式携带 agent 身份。

之下是一个严肃的 LLM 与 MCP 网关。

Agent Runtime 的可信度取决于底层资源路径。AgentGuide 在同一个 自托管 Runtime 中提供已经实现的 LLM 与 MCP 网关路径。

llm gateway

一个 API 接入多个受支持的 Provider

  • OpenAI、Anthropic、Gemini、DeepSeek、通义千问、智谱、OpenRouter、Ollama 等
  • OpenAI 与 Anthropic 兼容端点，外加 Claude Code 即插即用的 CLI profile
  • 逻辑模型路由：一个模型名、多个候选提供商、自动回退
  • 凭据池化调度 —— 包括 CLI 订阅凭据（Codex、Claude Code）

mcp gateway

工具成为受治理的基础设施

  • MCP 服务注册一次，即可经由带鉴权策略的路由对外暴露
